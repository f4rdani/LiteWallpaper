Arsitektur & Inovasi

Fitur Unggulan MiniWallpaper

Didesain dari baris pertama untuk efisiensi ekstrim tanpa membebani sistem saat bekerja maupun bermain game.

Zero-Copy D3D11VA Decode

Stream video didekode langsung di chip hardware GPU (NVDEC / Intel QSV / AMD VCN) via D3D11 Texture2DArray SRV tanpa penyalinan CPU-ke-GPU.

True Hardware Acceleration

Smart Dual-GPU Routing

Secara otomatis memprioritaskan Integrated GPU (iGPU) hemat daya untuk rendering, membiarkan discrete GPU (NVIDIA/AMD) tetap berada pada status deep sleep 0%.

Battery & Thermal Friendly

Gaming Auto-Sleep & Governor

Otomatis pause instan saat game fullscreen aktif. Mengaktifkan Deep Sleep (0% CPU, 0 MB VRAM) saat RAM atau VRAM sistem mencapai ambang batas (>= 80%).

100% FPS Game Preserved

Adaptive Boot Readiness Gate

Startup Windows tetap cepat berkat 9 DLL berat (FFmpeg & D3D11) yang berstatus delay-load. Wallpaper statis tampil detik ke-0, engine aktif saat CPU tenang.

31 ms CPU Boot Window

Sinkronisasi Layar Kunci

Ekstrak snapshot frame video secara presisi dan sinkronkan ke Lock Screen Windows serta companion screensaver native MiniWallpaper.scr.

Stamp Cache Anti-Redundant

1080p Video Auto-Optimizer

Pre-scaler bawaan yang mengonversi video 4K/bitrate tinggi menjadi format hardware 1080p NV12 yang menghemat daya hingga 75%.

Instalasi Cepat

Cara Pasang & Konfigurasi

Tidak membutuhkan instalasi rumit. Sepenuhnya portabel dan siap dijalankan dalam hitungan detik.

1

Unduh & Ekstrak Berkas

Unduh arsip portable terbaru (MiniWallpaper-Portable-...-win64.zip) dari halaman GitHub Releases. Ekstrak seluruh isi file ZIP ke folder permanen pilihan Anda (contoh: D:\MiniWallpaper\).

Penting: Jangan memindahkan file MiniWallpaper.exe sendirian keluar dari foldernya tanpa file DLL pendamping.
2

Jalankan MiniWallpaper.exe

Klik dua kali MiniWallpaper.exe. Ikon aplikasi akan langsung aktif di System Tray taskbar (samping jam).

Bila muncul dialog Windows SmartScreen (Windows protected your PC), klik 'More info' lalu pilih 'Run anyway' karena binary open-source belum menggunakan sertifikat berbayar.
3

Tambahkan Video Favorit Anda

Klik kanan ikon tray -> Control Panel, atau buka jendela aplikasi. Anda cukup drag & drop berkas video (MP4, WebM, MKV, MOV) ke galeri untuk langsung menjadikannya wallpaper hidup.

Konfigurasi Jalankan saat Windows Menyala

Buka Control Panel -> Tab General (Pengaturan Umum), lalu aktifkan switch 'Jalankan Otomatis saat Startup'. MiniWallpaper secara otomatis mendaftarkan autostart native Explorer tanpa menulis override registri yang mengganggu kestabilan sistem.

Logon Flag: MiniWallpaper.exe --startup
Boot Overhead: ~31 ms CPU time (Delay-loaded FFmpeg & D3D11)
Native Handoff: Menampilkan wallpaper statis langsung sejak detik ke-0

Pasang Screensaver Bawaan (MiniWallpaper.scr)

Di dalam folder aplikasi terdapat file bernama MiniWallpaper.scr. Klik kanan berkas tersebut lalu pilih 'Install'. Dialog pengaturan Screensaver Windows akan terbuka dan otomatis memilih MiniWallpaper sebagai screensaver utama.

rundll32.exe desk.cpl,InstallScreenSaver MiniWallpaper.scr
Bantuan Teknis

Troubleshooting & Masalah Umum

Solusi cepat untuk kendala umum yang sering ditemui pengguna.

Layar hitam atau video wallpaper tidak muncul di desktop?

Pastikan opsi 'Show desktop icons' dalam keadaan aktif (klik kanan desktop -> View -> centang 'Show desktop icons'). Windows WorkerW membutuhkan ikon desktop aktif untuk menempatkan jendela wallpaper di belakangnya. Pastikan juga file video tidak rusak dan menggunakan format standar (H.264/HEVC/AV1/VP9).

Peringatan 'Windows Protected Your PC' (SmartScreen) muncul saat dijalankan?

Hal ini lumrah terjadi pada software open-source baru yang didistribusikan gratis tanpa sertifikat EV berbayar Microsoft. Klik 'More info' lalu klik 'Run anyway'. Seluruh kode sumber MiniWallpaper 100% terbuka dan dapat diaudit secara publik di GitHub.

Video terasa berat, patah-patah, atau membebani kartu grafis?

Gunakan fitur bawaan 'Optimize Video (4K -> 1080p)' pada tab Wallpaper Gallery. Video 4K mendekode piksel 4x lipat lebih banyak dibandingkan 1080p. Dengan optimasi hardware NV12 bawaan, beban GPU akan turun drastis hingga 75%.

Wallpaper otomatis berhenti saat bermain game atau menjalankan aplikasi berat?

Ini adalah fitur proteksi sistem bernama 'Auto-Pause on Fullscreen' dan 'Gaming Auto-Sleep'. MiniWallpaper secara cerdas menghentikan dekoder dan membebaskan VRAM ke 0 MB saat game aktif agar FPS game Anda tetap 100% maksimal. Begitu game ditutup, wallpaper akan otomatis resume kembali.

Suara video wallpaper tidak terdengar sama sekali?

Secara default wallpaper dimulai dalam kondisi bisu (muted) demi kenyamanan. Buka Control Panel -> Tab General, aktifkan tombol Audio dan sesuaikan volume sesuai keinginan Anda.

Wallpaper hilang atau tidak menyesuaikan saat menyambung monitor eksternal?

MiniWallpaper memantau event sistem WM_DISPLAYCHANGE secara real-time. Jika Anda baru saja mencolok monitor baru atau mengubah orientasi, klik tombol Refresh di rail menu galeri atau pilih monitor target pada banner multi-monitor di galeri.

Bagaimana cara mereset seluruh konfigurasi ke kondisi awal?

Buka Windows Run (Win + R), ketik %APPDATA%\MiniWallpaper lalu tekan Enter. Hapus berkas config.json kemudian jalankan ulang MiniWallpaper.exe. Aplikasi akan membuat konfigurasi default baru yang bersih.
